# Rature: privacy and support pages

Hosted **privacy policy** and **support** pages for the Rature poetry notebook app, published with GitHub Pages. The app itself lives in a separate private repository; this repo contains only the public pages the store listings link to.

- Privacy policy → [`privacy.html`](./privacy.html)
- Support → [`support.html`](./support.html)

Live: https://octavator.github.io/rature-legal/

The privacy text is a hand-made HTML copy of `store/privacy.md` in the app repo. When one changes, update the other and the "last updated" date.
